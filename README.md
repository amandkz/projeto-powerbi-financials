# Projeto de Análise Financeira - Power BI

Este repositório contém o projeto desenvolvido no âmbito do bootcamp de Análise de Dados da DIO, utilizando o Power BI Desktop e o dataset `financials`.

## 📊 Sobre o Projeto
O objetivo principal deste projeto foi criar um relatório financeiro interativo para apoiar a tomada de decisões estratégicas, transformando dados brutos em insights visuais claros.

## 🚀 Tecnologias e Ferramentas Utilizadas
* **Power BI Desktop**: Construção do modelo de dados e visualizações.
* **Microsoft Excel**: Fonte de dados base (`Financial Sample.xlsx`).
* **GitHub**: Controlo de versão e hospedagem do código/projeto.

## 📈 Funcionalidades do Relatório
* **KPIs Principais**: Cartões de resumo com o *Total de Vendas* e *Total de Lucro*.
* **Análise Temporal e Geográfica**:
  * Gráfico de colunas com o desempenho de vendas por país.
  * Mapas interativos detalhando o volume de vendas, unidades comercializadas e a distribuição geográfica do lucro.
* **Análise por Segmento**: Gráfico de pizza destacando o lucro gerado por cada segmento de mercado (com destaque para o setor *Government*).

## 📂 Estrutura do Repositório
* `sample_financial.pbix`: Ficheiro principal do projeto Power BI.
* `Financial Sample.xlsx`: Base de dados utilizada para alimentar o relatório.
